# 固定 Origin 版本上的开源候选实测

日期：2026-09-11。目标是个人可以分享给同学和教授的插件；目标运行端为用户已安装的 Origin 2026b SR2 10.350243、Windows x64、普通版。测试不涉及学校官方发布。

## 候选与运行条件

- 上游：[Ge-Shun/origin-mcp](https://github.com/Ge-Shun/origin-mcp)，v0.1.4，commit `fecb7226ed60d7651d921d2586eb9950bf16b618`。
- Python 3.12.14；独立测试环境；originpro 1.1.15、OriginExt 1.2.5、pandas 3.0.5。
- 第一次遵循上游依赖范围安装，解析到 MCP 2.2.0；导入 `mcp.server.fastmcp` 失败。固定 MCP 1.30.0 后可启动。
- 使用上游 `OriginEmbeddedBridgeServer` 的串行派发类，运行于独立 Python 进程，通过外部 originpro 创建测试 Origin。未调用 `attach()`；未测试上游 OPX 安装或在用户正在编辑的 Origin 中启动。
- 每次测试使用独立合成数据、临时端口、临时本地认证及输出目录；测试后关闭自己创建的 Origin，不修改当前已安装插件配置。
- 客户端使用 MCP 2 的真实 stdio Client；初始新协议探测被 MCP 1 服务拒绝，随后兼容回退并完成工具调用。这不是 Claude、ChatGPT 或 WorkBuddy 模型调用测试。

## 实际结果

严格验收运行完成 17 次工具调用、9 项检查，其中 8 项通过、1 项失败，**整体未通过**。一开始仅观察外层 `ok` 的探索运行不能作为验收通过证据。

| 检查 | 结果与证据 |
|---|---|
| CSV 导入与回读 | 51 行；首行 `0, 2.3, 0.1` 与合成输入一致 |
| 原生线性拟合 | 截距 `0.09999999999999964`，斜率 `0.20000000000000007`；对已知 `0.1, 0.2` 的绝对误差小于 `1e-9` |
| 结构化非线性拟合 | **失败**；外层 `ok: true`，内部 `executed: false`、`result: false`、参数为空 |
| 平滑 | Origin 报告执行成功；本检查没有独立验证平滑后数值，不能当作完整算法验收 |
| 连续编辑单元格 | 修改为 `0.123` 后回读一致 |
| 矩阵写入与回读 | `[[1,2,3],[4,5,6]]` 一致 |
| 保存并重新打开 | OPJU 重新打开后修改值仍为 `0.123`；文件非空 |
| 图形 | PNG 解码通过，实际查看两条合成曲线；两条线同色，尚不构成最终出版图验收 |

失败的上游拟合命令为 `nlfit iy:=[Candidate]1!(1, 2) function:="ExpDec1" init_y0:=0.2 init_A1:=1.8 init_t1:=1.0;`。不能据此认定 Origin 的 ExpDec1 不可用：本项目原型已经通过 `op.NLFit('ExpDec1')` 在同一 Origin 上恢复 `y0=0.3, A1=2.0, t1=1.4`，并作数值断言。问题位于该候选调用路径及错误传播，而非这个授权版本缺少非线性拟合。

## 性能与额度

此次 17 步累计 21.687 秒，不包含独立 Origin 的冷启动。会话内单元格写/读约 `0.078/0.063` 秒，图形标签修改 `0.094` 秒；带首次导入及导出的绘图为 `10.704` 秒。这是单机单次合成测试，不是跨电脑基准或稳定性承诺。

上游 full 模式实际列出 237 个工具，序列化工具说明约 379,300 字节。源代码默认 compact 模式为 25 个工具；这说明直接向模型暴露所有细粒度工具会增加上下文负担，不能以工具数量代表完整覆盖。产品应采用少量入口、按需检索参数、批量执行、默认小摘要和按需读取完整结果。

## 采用决定

现成项目值得复用，但本次没有找到并验证一个已经满足全部目标的即用发行版。保留其知识组织、对象适配与会话设计作为候选；先修复失败传播并对分析适配逐类验证，再决定进入分享包的模块。Origin Agent Bridge 已有的便携运行环境、输入快照、程序执行、原生数值断言和多宿主封装继续作为产品基础。

完整目标的实现路线：**官方接口优先 → 持续会话与检查点 → GUI 功能补齐 → 结果回读 → 功能分类验收 → 无需 Python/JSON 的分享安装**。学习成本降低的验收是用户只表达目标、确认影响科学结果的参数并审查结果；不能把编写 LabTalk/Python 的负担转给用户。

## 重现

在单独的候选环境安装固定 commit、`mcp==1.30.0`、`originpro==1.1.15` 和 `OriginExt==1.2.5`；本项目开发环境作为 MCP Client。然后运行 `scripts/verify_candidate.py --candidate-dir <checkout> --candidate-python <candidate-python.exe> --output <new-directory>`。脚本固定 commit、创建自己的 Origin 和认证会话、保存逐工具结果并在严格检查未通过时返回非零。

GUI、第三方 Apps、全部统计分析、取消/崩溃恢复、嵌入式 OPX、多 Windows 用户和各宿主实际模型调用尚未由此测试覆盖。当前分享包没有引入候选源码。
